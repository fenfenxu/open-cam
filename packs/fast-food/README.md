# 快餐店方案包

应用本包会创建 4 路摄像头（门口 / 点餐 / 后厨 / 店内），每路带一段演示视频源，可先跑通规则再换成真实源。

包含规则（各挂在对应路上）：

- **门口进出客流**（line_crossing，门口）：穿越门口横线即计数，区分进/出方向；同一目标回到原侧才会再次计数。
- **点餐区排队超员**（zone_count，点餐）：点餐区域内人数 ≥ 5 触发。
- **后厨闯入**（zone_intrusion，后厨）：有人进入后厨区域触发。
- **闭店后入侵**（zone_intrusion + active_hours 22:00-07:00，店内）：只在闭店时段生效的全画面入侵告警。

演示源可先跑；到摄像头页改成真实 RTSP/文件后再启动。规则页请按实际画面调整线段与区域：越线的两个端点顺序决定「进」的方向（沿第一点→第二点看，左→右为进）。
